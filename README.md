# 🧒 Montessori Math Games Collection

Bộ sưu tập 159 trò chơi toán học Montessori cho trẻ 3-12 tuổi, kèm React app mẫu.

## 📁 Cấu trúc

```
├── montessori-*.md          # 159 bài requirement trò chơi toán học
├── montessori-index.md      # Mục lục tổng hợp
└── sample-montessori-57/    # React app mẫu cho bài #57
```

## 🎮 Sample: Wooden Hierarchy Material (#57)

Game tương tác giúp trẻ 6-9 tuổi hiểu hệ thống phân cấp số (đơn vị → nghìn → triệu) qua 3 giai đoạn:

1. **🔍 Khám phá** — Click vào 9 khối gỗ mã màu để xem tên và giá trị
2. **❓ Trắc nghiệm** — Tìm đúng khối theo tên/giá trị (5 câu)
3. **🏗️ Xây số** — Ghép các khối để tạo số lớn (3 lượt)

### Chạy thử

```bash
cd sample-montessori-57
npm install
npm run dev
```

Mở http://localhost:5173

### Tech stack

- React 19 + Vite
- CSS-only shapes (không dùng thư viện UI)
- Tiếng Việt

## 📚 Nội dung Montessori

Các bài requirement bao gồm:
- Độ tuổi phù hợp
- Mục tiêu học tập
- Dụng cụ cần thiết
- Cách chơi chi tiết
- Quy luật toán học
- Bài mở rộng
- Tài liệu tham khảo
